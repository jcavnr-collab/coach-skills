# Process checklist

Use only the questions that affect the requested diagram.

- What event begins the work, and what observable result completes it?
- Who owns each decision and each handoff?
- What information arrives, and where does the authoritative record live?
- Which steps are automatic, and which require a person?
- What must be approved before sending, publishing, billing or changing an athlete's plan?
- Where do rejected work, missing information and failures return?
- Which services are verified connections, and which are proposed?
- Which steps are optional, and what changes if they are skipped?

For a small process, one connected flow is enough. For a larger system, retain an overview and add detail views where a single canvas would become unreadable. Technical examples should come from verified specifications or be explicitly marked illustrative.
