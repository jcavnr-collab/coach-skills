# Cinch document brand

Verified against CinchOS's current tenant design tokens on October 26, 2026. This package freezes that palette for reproducible documents; refresh it deliberately if Cinch approves a new identity.

| Role | Color | Use |
|---|---|---|
| Ink blue | `#1E3A52` | Titles, headings, links, optional next-step button |
| Graphite | `#15181C` | Body text |
| Secondary graphite | `#41464D` | Captions and metadata |
| Amber | `#D89A3D` | Short accent rule and small markers |
| Teal | `#2E9EA1` | Diagram accents and callout rule |
| Warm bone | `#F7F5F0` | Screen canvas outside the white page |
| White | `#FFFFFF` | Printed page and readable button text |
| Hairline | `#C2C7CD` | Table and section separators |

Use **Epilogue** for headings and the live-text Cinch Cycling name. Use **Open Sans** for prose, tables, and captions. The unmodified variable fonts are bundled under SIL OFL 1.1; their license files and upstream URLs are in `assets/fonts/`. Code samples use the system monospace family to preserve command characters.

Keep the page white, body text at approximately 11 pt, generous line spacing, and restrained color. Amber and teal are small accents, not body-text colors on white. Use sentence case headings, hairline tables, and images at their original aspect ratio. Add color to explain a process, not to decorate every section.

The renderer uses a typographic brand name, not a recreated Cinch logo. Cinch's name and identity remain its property. A generated paper should use the actual author's attribution and only contact details supplied for that document.
